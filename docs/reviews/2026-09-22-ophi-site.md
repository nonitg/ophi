# Ophi public site — completed local redesign

The public brand is now Ophi, with canonical and social metadata for https://ophi.app.
This task updates the public website and its design/product documentation. It does not rename the
internal Python package or provision a production domain.

## Final design

The previous lightbox and subsequent conventional multi-section draft are replaced by one editorial
composition. Oversized Fraunces type shares space with an original interactive tooth sculpture.
A short introduction and inline signup remain immediately available. Context and the cited statistic
live in “Why Ophi?”; privacy details are a separate native dialog. Repeated geography, filler copy,
chart, manifesto, FAQ stack and oversized footer were removed.
